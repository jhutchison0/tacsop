**CONCERN 5.A**: Protocol line 73 says "recursive scan of `~/projects/` for any directory containing `.claude/commands/`". ## Deep Dive: The Three Most Material Findings

### Material Finding 1 (CONCERN 5.A) — Protocol PROJECTS_DIR misdescription

**File**: `docs/propagation-protocol.md:73`

**What it says**: "The script discovers downstream repos by recursive scan of `~/projects/` for any directory containing `.claude/commands/`."

**What the script does**: `PROJECTS_DIR = UTILS_ROOT.parent.parent`, which for the current checkout layout (`~/projects/github/utils/`) is `~/projects/github/`, not `~/projects/`.

**Why it matters**: This is the kind of documentation drift that bites a downstream maintainer who tries to reason about which sibling repos will be notified. If the proposer of a future propagation reads the protocol, says "ah, this will hit all my `~/projects/*` directories," and then notices repos missing from the propagation list, they will not initially suspect the protocol's claim is wrong — they will suspect the script is buggy. Costs an investigation session to discover the misdescription.

**Fix**: Change the protocol prose to "the grandparent directory of the utils repo (currently `~/projects/github/`, since utils lives at `~/projects/github/utils/`). Any repo containing a `.claude/commands/` directory under this root is discovered." Or, lift `PROJECTS_DIR` resolution to be configurable via `project.yaml`.

### Material Finding 2 (CONCERN 7.A) — Per-artifact adoption mode not specified

**Files affected**: All Pass 2 new/modified artifacts, eventual `docs/doctrine-updates.md` entry.

**What is missing**: A per-artifact classification of "template-copy (replace your file)" vs "customize-per-repo (use as a structural template, fill in your content)" vs "skip (utils-only)".

**Why it matters**: Without this, propagating the Pass 2 sprint to 11 (or 18) downstreams will produce inconsistent results. A maintainer who treats every file in the notification as "copy as-is" will inherit utils' decision-science vocabulary in their LANGUAGE.md. A maintainer who treats every file as "customize" will skip the format docs that should be copied verbatim. This is exactly the Pass 1 propagation-cost concern (F3) and the proposer's Contrarian B.

**Fix**: The eventual `docs/doctrine-updates.md` entry for this sprint should include a table like the one in Check 7.A above, and the propagation-protocol.md should be amended to require this table as part of any future doctrine entry (add to the Evaluation Gate or the Cycle Anatomy section).

### Material Finding 3 (CONCERN 9.A) — `.claude/README.md` not updated to reflect skill deletion

**File**: `.claude/README.md:36–42`

**What it says**: Lists `session-end.md` as a skill in the skills tree.

**Reality**: File deleted.

**Why it matters**: This is the only persistent README of the `.claude/` infrastructure. A user or agent reading it will look for a file that does not exist.
