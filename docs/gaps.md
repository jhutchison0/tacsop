# Gap Register

What this repo cannot see yet. Each gap names the collector that would close it and the decision it blocks; a gap with neither is not a gap. The list is never empty: an empty list is a finding about the people keeping it, not evidence the system is clean. Rule 5 of [maintaining-the-common-operating-picture](../.claude/skills/maintaining-the-common-operating-picture/SKILL.md).

A gap is never deleted. It closes when a collector now covers it or a measurement found it absent, and it is superseded when a newer row restates it. Either way the row keeps its place and its Status becomes `closed YYYY-MM-DD by <pointer>` or `superseded YYYY-MM-DD by <pointer>`, the pointer naming the probe, record, or row that replaced it. [tests/unit/test_gaps.py](../tests/unit/test_gaps.py) counts `open` rows only and fails when none remain, when an open row lacks either field (a filler such as `TBD` or `None exists.` alone counts as lacking it), or when a Status takes any other form. Keep the header as it is, and put no `|` character in a cell.
