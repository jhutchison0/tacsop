## How to Use This Roadmap

1. **Start each session** by checking which phase is active (`/session-start`)
2. **Track progress** by checking off milestones as they're completed
3. **Update `config/project.yaml`** when a phase status changes
4. **Add new phases** as the project's direction becomes clearer
5. **Don't plan too far ahead** — Phase 1 should be detailed, Phase 3+ can be vague
